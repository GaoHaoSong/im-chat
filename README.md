# IM Chat

局域网 Python + Vue 3 IM 网页聊天工具。

## 功能

- 用户名 + PIN 注册 / 登录 / 自动登录 / 退出登录
- 一对一实时聊天（文字 / 表情 / 图片 / 文件）
- 消息撤回（2 分钟内）、未读计数、时间戳、历史翻页
- @提及、引用回复
- 在线/离线分组（可折叠）
- PC 两栏 + 手机单栏切换布局

## 启动

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

浏览器访问 http://localhost:8000，局域网内其他设备访问 http://<你的IP>:8000。

## 测试

```bash
pytest
```

## 手动验收清单

打开两个浏览器（或同一浏览器的常规窗口 + 隐身窗口），分别注册 alice / bob：

- [ ] alice 注册后自动登录 → 主界面显示自己 + 默认折叠的"离线"组
- [ ] bob 注册后 → alice 的"在线"组实时出现 bob
- [ ] alice 选中 bob → 发文字 → bob 实时收到，且界面显示气泡
- [ ] alice 关闭浏览器再打开 → 自动登录到主界面
- [ ] bob 在 alice 离线时发送消息 → alice 上线后用户列表显示未读数
- [ ] 点击 bob → 未读数清零
- [ ] 发表情 / 图片 / 文件 → 双方都正常显示和下载
- [ ] 撤回 2 分钟内的消息 → 双方显示"该消息已撤回"
- [ ] 撤回超过 2 分钟的消息 → banner 提示超时
- [ ] @bob 写消息 → 消息中 @bob 高亮显示
- [ ] 右键消息 → 引用回复 → 输入框出现引用 banner → 发送后对方显示引用块
- [ ] 同一账号在第二个浏览器登录 → 第一个浏览器显示"你已在其他设备登录"
- [ ] 点击退出登录 → 返回登录页，token 失效
- [ ] DevTools 切换手机视口 → 单栏布局生效，← 返回正常
- [ ] 关掉服务再启动 → 重新打开页面历史消息仍在，断线 banner → 恢复后消失

## 目录结构

- `app/` Python 后端 + 静态前端
- `data/` 运行时数据（数据库 + 上传文件，不入库）
- `tests/` pytest 测试
